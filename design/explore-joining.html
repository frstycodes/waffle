Joining a server

Discord's four post-join gates, in the order Discord runs them: onboarding questions (rules as their last step), the rules gate in the composer for servers without onboarding, Channels & Roles, and the Server Guide. Labels and order are Discord's (docs/discord-joining-re.md); the look and the "do better" items are Waffle's.

0 · Accepting an invite

Opening an invite link shows this before anything joins. On the right is the server's invite splash, the image the server set for its invites; servers without one get a plain panel and the card narrows to one column. Server Settings opens in place: Server Nickname (only when the invite allows it, 32 characters), Allow direct messages and Show your activity status. They apply once you've joined. No Thanks closes it.

1 · Rules in the composer

A pending member (rules gate on, no onboarding) can read every channel. The composer is the bar until they agree. Complete opens the dialog; Submit sends PUT /guilds/{id}/requests/@me. Do better: Submit never greys out; pressing it unticked says what's missing.

2 · Onboarding

The server's invite splash fills the screen behind it when it has one (Discord's onboarding reads the same image); without one it's the plain page. Full screen over the app, right after joining a server with onboarding on. Cover (moves on after 3 s), each question, then Read & Agree to Server Rules when the rules gate is on. Buttons are Discord's: Skip with nothing picked, Next once something is, Finish 🎉 on the last step, Back after the first. Finishing sends POST /guilds/{id}/onboarding-responses. Do better: each answer lists the channels and role it adds; required questions and unread rules never grey the button, pressing it says why.

3 · Channel list entries

Rows at the top of the channel list, in Discord's order: Get Started progress (new members, 7 days), Server Guide, then Channels & Roles (Browse Channels when the server has no questions). Do better: closing onboarding halfway leaves Finish joining first, with progress dots, resuming at the first unanswered question.

The server menu gains Show All Channels (checked when channel picking is off). With it off, the list shows only followed channels, plus any channel that mentions you.

4 · Channels & Roles

Opens in the main view like a channel. Customize lists every question, answers saving a second after you stop clicking (PUT …/onboarding-responses). Browse Channels lists every channel you can see with a checkbox; the category's box is Discord's Follow Category. Saves via PATCH /users/@me/guilds/settings. Do better: a live "You see 6 of 10" count, and locked rows say why.

5 · Server Guide

The Server Guide row opens this page: banner, the welcome message from the people the server named, Get Started to-dos (each opens its channel; viewing or sending there ticks it), and Resources (read-only channels). A to-do's channel shows a bar under the header until done: its title, then Next: ….

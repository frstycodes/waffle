Report

Discord's report flow is a menu the server sends, one screen per node: pick a reason, narrow it down, Submit Report, then a thank-you screen offering Block and Mute. Waffle draws Discord's nodes in its own look. The reasons below are placeholders: the real ones come from GET /reporting/menu/message and aren't in the client.

Where it is

Last in the message menu's destructive group, under Delete Message, and in the person menu. It's hidden on your own messages, system messages and "friend request accepted" notices, and for yourself and for bots that aren't users.

The dialog

Reasons advance in one click, as Discord's do. Back pops one screen and keeps what you picked. On the submit screen, Waffle adds Also block beside Submit Report (better.html), so you don't need a second step on the thank-you screen. When it's ticked, the thank-you screen shows Block as already done.

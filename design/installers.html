Installers

The first thing anyone sees of Waffle. On macOS it's a disk image window: a still picture Finder lays its icons over. On Windows it's Waffle's own one-click installer, built with the app's design system, so there's no wizard to click through.

macOS disk image

One still image, 660×400 plus @2x; Finder can't animate it or swap it for dark mode. Finder draws the labels, black in light mode and white in dark, so the band under the icons is honey amber #A66800: 4.6:1 against black, 4.6:1 against white. The dipper and the waffle stay clear of the icons and their labels.

Windows installer

Waffle installs per user, so there's nothing to choose: the installer opens, installs into AppData, adds the Start menu entry and opens Waffle. It follows the system theme. Waffle.exe ships inside the installer, so nothing downloads; the count is what's been written to disk. A failure (a full drive, a folder it can't write to) stays open, says what went wrong and offers Try again.

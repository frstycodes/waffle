Storage. Synced to your Discord account, as Discord does: chat message display, show user avatars, the two image switches, spoilers, convert emoticons, GIFs, animated emoji and sticker animations (Discord's gif_auto_play, animate_emoji, animate_stickers and others). Kept on this computer, as Discord does: text size, group spacing, zoom, saturation, role colors, high contrast, indicators, reduced motion, notification duration, TTS rate, send button. UI density syncs in Discord (ui_density), but only in the newer settings format that Waffle doesn't use, so Waffle keeps it on this computer.

Left out

  • Ash, Dark and Onyx themes. They're Discord's palettes. Waffle keeps Light and Midnight.
  • Create or join a server (⌘⇧N), create a thread, soundboard (⌘⇧B). Waffle doesn't have these features yet, so the shortcuts would do nothing.
  • Open in split view, games in autocomplete, legacy chat input, rich-input preview. These are tied to features Waffle doesn't have.
  • Official messages, HDR, custom cursor, sync contrast. These are experiments, or Windows only.
  • Bold, italic and underline keys, and ⌘, for settings. Discord has no default keybind for these.
  • Lofi with Wumpus, Raging Demon. These are Discord's own easter eggs.

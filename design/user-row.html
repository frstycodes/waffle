User row

The user area at the foot of the sidebar. Discord's behaviour is read from its shipped client (discord.com bundle and CSS, 2026-11-24); Waffle's is user_panel in src/layout.rs as it stands on main. Both columns follow the page theme.

Discord source: container_g6VwXp, audioButtonParent_gKpIZP, button_Y-8oZW, hoverRoll_Dq3ch1, the account panel class r4 and its status renderer. Icons on both sides are Phosphor stand-ins. Not verified: camera, stop-streaming and activity tooltips, Discord's ping quality thresholds and ping mark colours, the activity panel's contents, which of Discord's dark themes is the default (Dark is drawn; Ash is in the playground), Discord's default sidebar width (its resize handle runs 264–432 and --custom-guild-sidebar-width is 268, so 268 is used; Waffle's is 68 + 240 = 308), idle, dnd and streaming mark colours, the gear's hover animation (Discord plays a Lottie), what the server-muted click shows.

Playground

Set the state on the left, then hover and click either panel. Clicks drive one shared state, so you see both apps answer the same action; each log says what that app does.

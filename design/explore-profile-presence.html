Optional: Show more as Discord's peek

What Discord's popout does, read from its web client (modules 646986 and 80330, CSS container_M2WrKU): under a "Current activity" heading it renders only the first card (a stream, then activities, then voice). With more than one, a second card peeks 8px out from under it, inset 8px each side. Hovering lifts the first card 2px and the peek grows to 12px (200ms ease-in-out). Clicking the peek ("View More") opens the full profile on its Activity tab. No count, no dots, no carousel. Recent activity lives only in the full profile, not the popout.

Editing your profile

Settings › Profiles, Discord's two tabs. The preview is the real popout and updates as you type. Nothing saves until Save changes; the bar names what changed. Switching tab or server with unsaved changes is refused and the bar shakes, as Discord does. Items only Nitro can set (decoration, nameplate, effect, frame, theme, banner image) share one row that opens Discord.

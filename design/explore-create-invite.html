Create and invite

Discord's three flows beside Waffle's. Both columns share one state: click through either and the other follows. The Discord column is a reference drawn from its client (copy from the bundles, layout from memory), not a screenshot. The chips switch the server's state.

Create a server

From the rail's + (Ctrl/Cmd+Shift+N). Waffle adds: each template lists the channels it creates; the server limit shows before you press anything.

Create channel

From a category's + or the channel list's menu. Private channel and Stage pick their members, roles or moderators in a second step behind Next, as in Discord.

Invite people

From a channel's invite button or the server menu. Waffle adds: link settings open in place, and paused invites say so instead of handing out a link that won't work.

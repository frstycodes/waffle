Forum: picking and editing tags

Up to five tags a post. In the composer, once five are picked the rest dim. When the forum requires a tag, Post stays enabled and the error shows on Post. Edit Tags on a post's right-click menu saves each tick at once.

A tag is required to create a post in this channel

Other errors, on Post: "A title is required" and "A message is required". Opening New Post in a forum with guidelines unfolds them the first time.

Edit Tags appears for the post's author and anyone with Manage Threads, when the forum has tags. At 5 the unticked ones are disabled. Each tick sends the new tag list right away, reopening the post first if it was archived.

Announcements: Publish

You can publish your own message in an announcement channel if you can send messages there, or anyone's with Manage Messages. Publish lives in the hover toolbar. Right after you post, a strip under the message offers it once. Publishing sends a copy to every server following the channel.

Announcements: Follow

Anyone can follow an announcement channel into a server where they can manage webhooks. Entry points: a Follow button in the channel header, and for people who can't post there, a strip where the composer would be.
